TEKO TUKU - WEBSITE TOKO ONLINE SEDERHANA

ISI FOLDER
- index.html : halaman toko online
- admin.html : dashboard admin
- style.css  : desain website
- script.js  : pencarian, kategori, keranjang, checkout WhatsApp
- admin.js   : tambah, edit, hapus produk
- images/    : tempat menyimpan foto produk (opsional)

CARA MENJALANKAN
1. Ekstrak folder TEKO-TUKU.
2. Buka index.html di browser untuk melihat toko.
3. Buka admin.html untuk mengelola produk.
4. Pastikan kedua halaman dibuka pada browser dan alamat (origin) yang sama agar LocalStorage terbagi.

PENTING
- Ganti nomor WhatsApp 6281234567890 pada bagian STORE_WHATSAPP di script.js.
- Harga dan daftar produk awal adalah contoh. Ubah melalui admin.html.
- Data produk dan keranjang disimpan di LocalStorage browser, bukan database online.
- GitHub Pages adalah hosting statis. Perubahan LocalStorage di dashboard admin tidak otomatis terlihat oleh pengunjung lain atau perangkat lain.
- Dashboard admin tanpa password tidak aman untuk pengelolaan toko publik. Jangan gunakan sebagai panel admin publik untuk data toko sungguhan.
- Foto produk contoh memakai placeholder online. Ganti URL gambar melalui dashboard admin dengan URL foto produk Anda.
