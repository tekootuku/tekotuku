Folder untuk foto produk.

Cara pakai:
1. Letakkan file foto (jpg/png/webp) di folder ini, misalnya: ram-ddr4.jpg
2. Di halaman admin, isi kolom "URL atau path gambar" dengan:
   assets/produk/ram-ddr4.jpg
3. Simpan produk. Foto akan tampil di kartu produk dan modal detail.

Catatan:
- Untuk hosting, folder assets/produk ikut di-upload bersama file website.
- Boleh juga memakai URL lengkap, misalnya https://i.imgur.com/xxxxx.jpg
- Kalau file tidak ditemukan, gambar di kartu akan disembunyikan otomatis.
- Data produk masih tersimpan di LocalStorage browser admin, bukan di server.
